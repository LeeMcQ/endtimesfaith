# End Times Faith

Live site: [leemcq.github.io/endtimesfaith](https://leemcq.github.io/endtimesfaith/)

Prophetic script generator plus this week’s SDA Adult Sabbath School lesson study.

## Use

1. Open the site and connect with your own API key. **Gemini** is recommended for the lesson tools ([free key](https://aistudio.google.com/apikey)). New Gemini keys start with `AQ.`; older keys start with `AIza`. Both work.
2. Generate End Times Faith subtitle scripts from a subject, as before.
3. Scroll to **This week’s lesson study** and run:
   - **Best questions** — ranked forum / YouTube / class questions (Gemini Search)
   - **Video script** — cinematic scholarly YouTube script
   - **Follow-up questions** — class, personal, and going-deeper questions

The lesson preview **updates automatically each week**. On load, the site reads the current Standard Adult quarterly from the official Adventech Sabbath School feed, picks this week’s lesson (Sabbath–Friday), and injects title, memory text, daily outline, and scriptures into those three prompts. Results are cached on your device for six hours.

Keys stay in your browser and are sent only to the provider you choose.
